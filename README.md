# COHERENT Website

Static launch website for the COHERENT Horizon Europe MSCA Staff Exchanges project.

## Files

- `index.html` - static tabbed website with page-style navigation
- `styles.css` - responsive visual design
- `script.js` - mobile navigation and active section state
- `assets/coherent-hero.png` - generated hero image for the project
- `assets/consortium-map.png` - consortium geography map
- `assets/coherent-logo.png` - official project logo used on the website
- `assets/coherent-logo-transparent.png` - transparent-background version for dark/royal-blue sections
- `assets/coherent-logo-cutout.png` - cutout version with white internal areas removed for hero/footer blending
- `assets/coherent-logo.svg` - previous SVG logo draft kept for reference
- `assets/coherent-logo-reverse.svg` - previous reverse SVG logo draft kept for reference
- `assets/eu-emblem.svg` - EU funding acknowledgement emblem
- `assets/partners/` - partner logo assets extracted from Part B2 where available

## Preview

Open `index.html` directly in a browser. No build step is required.

## Before Launch

- Replace the contact placeholder with the official project email.
- Replace the project-generated partner marks with official institute logos if the consortium approves their use.
- Replace the hand-built EU emblem with the official downloaded emblem package if required by the Grant Agreement communication rules.
- Add CORDIS and social media links when they are available.
